## ⚡ Quickstarts

### 1. Run via CLI
```bash
npx yariinfotech-mcp services
```

### 2. Connect to MCP in Claude Desktop or Cursor
Add the endpoint directly to your MCP client configuration (`claude_desktop_config.json` or `.cursor/mcp.json`):
```json
{
  "mcpServers": {
    "yari-infotech": {
      "url": "https://yariinfotech.com/mcp",
      "transport": "streamable-http"
    }
  }
}
```

### 3. Install Official Agent Skills
```bash
npx skills add yari-infotech/yari-skills
```
